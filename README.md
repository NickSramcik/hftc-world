# HFTC world

A vertex-lit, low-poly 3D model of the Hayward Fire Station #6 & Fire Training
Center campus, built from the City of Hayward's published 2019 bid set (site
plan and floor plans), with a small orange dragon to run, glide and fly
around it using PS1-platformer-style controls. Keyboard, gamepad and touch.

Live: https://nicksramcik.github.io/hftc-world/

Per the bid set, not as-built; trees, hills and some props are invented.
Built with Blender (scripted, as a Python runtime) and three.js r170 (MIT,
`vendor/THREE-LICENSE`).
